# Журнал работы

## 1. Датасеты и что предсказываем

### Датасет А (Текст): `Amazon Musical Instruments Reviews`
* **Данные:** Kaggle (`eswarchandt/amazon-music-reviews`), лицензия `CC0`. Из 10 261 отзыва фильтруем только гитарные (`guitar`, `pedal`, `amp`, `pickup`, `strings`, `fret`) — остается ~6 500 записей (берем 2 500–3 000).
* **Вход ($X$):** Текст отзыва (`reviewText` + `summary`).
* **Выход ($Y$):** Класс тональности (`Negative` [1–2], `Neutral` [3], `Positive` [4–5]) или основной аспект отзыва (`Звук/Тон`, `Сборка`, `Удобство`, `Цена`) на наше усмотрение.
* **Насколько подходит:** Полностью подходит по объему ($\ge 1000$) и лицензии. В базе сильный перекос в сторону 5 звезд, поэтому ручной сбор и генерация негативных/нейтральных отзывов дадут заметный прирост качества.
* **Обогащение:** Планируется выполнять с помощью иностранных торговых площадок для музыкальных инструментов.

### Датасет B (Аудио): `IDMT-SMT-Audio-Effects`
* **Данные:** Fraunhofer IDMT (Zenodo), лицензия `CC BY 4.0`. 55 044 файла `.wav` (44.1 кГц, 16-bit, Mono, по 2 сек) + XML-метаданные. Берем подвыборку электрогитар (`Gitarre monophon/polyphon`) на 3 500–4 500 записей.
* **Задача (не только классификация):** **Automatic Guitar Tone Matching** (одновременная классификация эффекта + регрессия настроек гитарного сетапа).
* **Вход ($X$):** Аудиозапись электрогитары (2–5 сек) в виде Лог-Мел-спектрограммы.
* **Выход ($Y$, двухголовая модель):**
  1. **Классификация:** Тип эффекта (`Clean/NoFX`, `Overdrive`, `Distortion`, `Fuzz`, `Chorus`, `Flanger`, `Phaser`, `Tremolo`, `Vibrato`, `Delay`, `Reverb`).
  2. **Регрессия (настройки ручек от `0.0` до `1.0`):** `Gain/Intensity` (из `fx_setting` в XML + компрессия), `Tone` (спектральный центроид) и 3 полосы эквалайзера `Bass`, `Mid`, `Treble` (доли энергии в полосах 80–250 Гц (Bass), 250–2000 Гц (Middle), 2000–6000 Гц (Treble)).
* **Насколько подходит:** Подходит по объему ($\ge 3000$) и лицензии. В XML уже есть тип эффекта и уровень `fx_setting`, а параметры эквалайзера/тона считаются из спектра (плюс на чистые сэмплы (сырой звук электрогитар) можно накладывать эффекты с точными настройками через различные плагины и внешние звуковые интерфейсы (гитарные процессоры)).
* **Обогащение:** Ручная запись аудиофайла с помощью процессора и пк + разметка соответствующего .wav данными из гитарного пресета (посмотреть числа настроек для соответствующих эффектов и обработок)

## 2. План по EDA (Разведочный анализ данных)

* **По текстам (`Amazon Reviews`):**
  * Фильтрация гитарных отзывов, очистка от пустых строк и дублей.
  * График баланса классов (показать нехватку негативных и нейтральных отзывов).
  * Распределение длины текстов (в словах/токенах) и топ частых слов по классам.
  * (окончательный выбор набора классов)
* **По аудио (`IDMT-SMT-Audio-Effects`):**
  * Парсинг XML, отбор записей электрогитары, проверка длительности, уровня громкости и тишины.
  * Распределение сэмплов по типам эффектов и уровням `fx_setting`.
  * Расчет таргетов эквалайзера (`Bass`, `Mid`, `Treble`, `Tone`, `Gain`), построение их распределений и визуализация мел-спектрограмм для разных педалей.

## 3. Что собираемся делать дальше

1. **Ручной сбор (по 50–100 примеров на класс):** парсинг свежих отзывов (*Thomann*, *Reddit*, *Ultimate-Guitar*) и запись своей электрогитары с разными настройками + сэмплы из *EGFxSet/Freesound*.
2. **Разметка в Label Studio:** составление правил (`codebook`), двойная разметка собранных данных вдвоем с замером времени, расчет `Percentage Agreement` и `Cohen's Kappa`.
3. **ИИ-обогащение (+100% объема):**
   * *Текст:* генерация через LLM + Back-Translation + синонимы (оценка через `Perplexity` и `UMAP/t-SNE`).
   * *Аудио:* генерация сетапов из чистых записей `NoFX` через `Pedalboard` + `SpecAugment` / `MixUp` (оценка через `FID`, `KS-тест` и `UMAP/t-SNE`).
4. **Обучение и сравнение:** обучение моделей на 4 версиях датасетов (базовый, +ручное, +ИИ, +совместное) с проверкой устойчивости к шуму.
